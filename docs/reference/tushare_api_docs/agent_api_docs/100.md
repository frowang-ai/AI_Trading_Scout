# 股票曾用名

**路径**: 股票数据/基础数据
**接口**: `namechange`
**描述**: 历史名称变更记录

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| ts_code | str | N | TS代码 |
| start_date | str | N | 公告开始日期 |
| end_date | str | N | 公告结束日期 |

## 输出参数

| 名称 | 类型 | 描述 |
|------|------|------|
| ts_code | str | TS代码 |
| name | str | 证券名称 |
| start_date | str | 开始日期 |
| end_date | str | 结束日期 |
| ann_date | str | 公告日期 |
| change_reason | str | 变更原因 |

## 调用示例

```python
pro = ts.pro_api()

df = pro.namechange(ts_code='600848.SH', fields='ts_code,name,start_date,end_date,change_reason')
```
