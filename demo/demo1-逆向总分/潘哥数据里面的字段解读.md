这是一个非常详细的指标列表，其中混合了**基础行情数据**、**经典技术指标**以及一些**衍生统计特征**（如连续天数 `_consec`）。

为了方便你理解和在量化系统中落地，我将这些字段分为五大类进行详细解读。

---

### 第一类：基础行情与量价数据 (Basic Market Data)

这部分是所有因子的“原材料”，直接反映市场的交易状态。

#### 1. `close`, `开盘`, `最高`, `最低`
*   **全称**：OHLC (Open, High, Low, Close)
*   **含义**：股票在特定周期的价格点。
*   **Quant用法**：
    *   **复权**：务必使用“前复权”价格计算策略收益，使用“不复权”价格判断涨跌停或关键心理价位。
    *   **Retuns**：计算 $R_t = \ln(P_t / P_{t-1})$。

#### 2. `成交量` (vol), `平均量比_50天` (volume_ratio)
*   **全称**：Volume, Volume Ratio
*   **含义**：
    *   **成交量**：当日成交的股票数量（注意区分“手”和“股”，Tushare通常单位是手）。
    *   **量比**：当日成交量 / 过去N日平均成交量。你的CSV中特指50天均值。
*   **Intuition**：量在价先。放量（量比>1）通常意味着分歧加大或新资金入场；缩量意味着市场惜售或无人关注。
*   **计算**：$VR = \frac{Vol_t}{MA(Vol, 50)}$

#### 3. `换手率%` (turnover_rate)
*   **全称**：Turnover Rate
*   **含义**：成交量 / 流通股本。
*   **Intuition**：反映股票的活跃度。
    *   低换手 (<1%)：冷门股/银行股。
    *   高换手 (>10% 或 >20%)：游资接力、情绪高潮或主力出货。
*   **Quant用法**：作为**流动性过滤器**（剔除低换手），或作为**情绪因子**（高换手通常伴随高波动）。

#### 4. `jump`
*   **全称**：Gap / Jump (跳空)
*   **含义**：今日开盘价与昨日收盘价（或昨日最高/低）之间出现断层。
*   **Intuition**：代表极其强烈的多头或空头意愿，通常由突发利好/利空引发。
*   **计算**：
    *   向上跳空：$Open_t > High_{t-1}$
    *   向下跳空：$Open_t < Low_{t-1}$

### 第二类：趋势型指标 (Trend Indicators)

这类指标用于判断价格运动的方向。

#### 1. `MACD` 家族 (`dif`, `dem`, `histgram`, `macd_signal`)
*   **全称**：Moving Average Convergence Divergence (异同移动平均线)
*   **组成**：
    *   `dif` (DIF): 快速均线(12) - 慢速均线(26)。代表短期趋势与长期趋势的偏离度。
    *   `dem` (DEA): DIF的9日平滑移动平均。代表DIF的趋势。
    *   `histgram` (MACD柱): (DIF - DEA) * 2。代表多空动能的强弱。
*   **Intuition**：
    *   DIF > 0：多头市场。
    *   柱子由绿变红：金叉，买入信号。
*   **Quant用法**：作为**趋势确认**过滤器。例如：只在 MACD > 0 时做多。

#### 2. `BOLL` 家族 (`bands_upper`, `bands_middle`, `bands_lower`)
*   **全称**：Bollinger Bands (布林带)
*   **组成**：
    *   `middle`: 20日移动平均线。
    *   `upper`: Middle + 2 * 标准差。
    *   `lower`: Middle - 2 * 标准差。
*   **Intuition**：价格通常在上下轨之间波动。
    *   **收口**：预示即将变盘。
    *   **触轨**：触及上轨可能回调（均值回归），也可能单边突破（趋势增强）。
*   **Quant用法**：**均值回归策略**（触碰下轨买入）或**波动率突破策略**（突破上轨买入）。

#### 3. `DMI` 家族 (`pdi`, `ndi`, `adx`)
*   **全称**：Directional Movement Index (趋向指标)
*   **含义**：
    *   `pdi` (+DI): 上升方向线，代表多头力量。
    *   `ndi` (MDI/-DI): 下降方向线，代表空头力量。
    *   `adx`: 平均趋向指数，代表**趋势的强度**（无论涨跌）。
*   **Intuition**：ADX > 25 代表有强趋势，ADX < 20 代表震荡市。PDI 上穿 MDI 为买点。
*   **Quant用法**：ADX 是极好的**择时过滤器**。在 ADX 高位时使用趋势策略，ADX 低位时使用网格/震荡策略。

#### 4. `DMA` (`dma`)
*   **全称**：Different of Moving Average
*   **含义**：两条均线的差值（类似MACD的DIF，通常是 MA(10) - MA(50)）。
*   **Intuition**：DMA > 0 代表短线高于长线，多头排列。

#### 5. `LON` 家族 (`lon`, `lonma`)
*   **全称**：Qianlong Long Term (钱龙长线指标)
*   **备注**：这是一个**中国特色指标**（源自通达信/钱龙软件），西方量化库（如TA-Lib）中没有。
*   **含义**：基于加权成交量的趋势指标。
*   **Intuition**：用于捕捉主力资金动向。LON 向上代表主力加仓。
*   **计算**：通常涉及价格变化率与成交量的加权平滑。

#### 6. `OBV` (`obv`)
*   **全称**：On-Balance Volume (能量潮)
*   **含义**：累积成交量。如果你今天涨，我就把今天的量加进去；如果跌，就减掉。
*   **Intuition**：**量在价先**。价格没涨但 OBV 创新高，预示主力吸筹。

### 第三类：摆动/超买超卖指标 (Oscillators)

这类指标用于寻找反转点。

#### 1. `KDJ` 家族 (`k`, `slowk`, `slowkdj`)
*   **全称**：Stochastic Oscillator (随机指标)
*   **含义**：当前价格在过去N天价格范围内的相对位置。
*   **Intuition**：
    *   K > 80: 超买（可能回调）。
    *   K < 20: 超卖（可能反弹）。
*   **Quant用法**：作为**短线反转因子**，或者在震荡市中高抛低吸。

#### 2. `RSI` (`rsi`)
*   **全称**：Relative Strength Index (相对强弱指标)
*   **含义**：一定时期内涨幅总和 / (涨幅总和 + 跌幅总和)。
*   **Intuition**：RSI > 80 代表多头力量过强，不仅是超买，也可能代表强者恒强。
*   **Quant用法**：
    *   **反转**：RSI(6) > 90 做空。
    *   **动量**：RSI(24) > 50 且上升，做多。

#### 3. `CCI` (`cci`, `cci_90`, `cci_-90`)
*   **全称**：Commodity Channel Index (顺势指标)
*   **含义**：价格与统计平均值的偏离程度。
*   **Intuition**：天生适合捕捉**暴涨暴跌**。
    *   CCI > 100: 进入异常强势区（打板客喜欢）。
    *   CCI < -100: 进入异常弱势区。
*   **字段解读**：`cci_90` 可能是指 CCI 上穿 90 的信号。

### 第四类：风险与统计指标 (Risk & Statistics)

#### 1. `BETA`
*   **全称**：Beta Coefficient
*   **含义**：个股相对于大盘（如沪深300）的波动敏感度。
*   **Intuition**：
    *   Beta = 1: 随大盘同涨同跌。
    *   Beta > 1: 弹性大（如券商、科技），大盘涨1%它涨2%。
    *   Beta < 1: 防御性（如银行、电力）。
*   **Quant用法**：用于**风控**（中性策略需对冲Beta）或**风格轮动**（牛市买高Beta）。

#### 2. `波动率` (volatile)
*   **全称**：Volatility (通常指历史波动率 HV)
*   **含义**：收益率的标准差。
*   **Intuition**：代表风险。波动率高意味着大起大落。

#### 3. `相关性` (Correlation)
*   **含义**：该股票与另一资产（可能是大盘，也可能是板块指数）的相关系数。

### 第五类：特殊的衍生后缀 (Derived Suffixes)

你的 CSV 中有很多带下划线的字段，这是特征工程（Feature Engineering）后的产物，不是原始API能直接拿到的，需要在**因子计算模块**中加工。

1.  **`_consec` (Consecutive)**: **连续满足条件的天数**。
    *   *例子*：`volume_consec` 可能指“连续放量天数”；`rsi_consec` 可能指“RSI连续大于80的天数”。
    *   *Quant价值*：这是非常强的**动量信号**。连续3天涨停比第一天涨停更说明妖股气质。
    *   *Pandas计算*：
        ```python
        # 计算 value > 0 的连续天数
        df['condition'] = df['value'] > 0
        df['consec'] = df.groupby((df['condition'] != df['condition'].shift(1)).cumsum()).cumcount() + 1
        ```

2.  **`_signal`**: **买卖信号**。
    *   通常指金叉（Golden Cross）或死叉（Death Cross）。
    *   *例子*：`macd_signal` = 1 当 DIF 上穿 DEA。

3.  **`_0` / `_90`**: **穿越特定阈值**。
    *   *例子*：`dif_0` 指 DIF 线上穿 0 轴；`cci_90` 指 CCI 上穿 90。
