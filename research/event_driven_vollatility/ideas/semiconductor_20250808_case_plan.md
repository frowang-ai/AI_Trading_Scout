# 2025-08-08 半导体主题周期案例计划

## 研究目的

用一个已知主题行情作为 sanity check，先校准“事件”和“主题周期”的可操作定义，再决定是否推广到全样本。

候选事件窗口：

```text
观察起点：2025-08-08
周期终点：2025-10-10
前置观察：2025-07-25 至 2025-08-07
```

## 事件定义

当前采用的工作定义：

> 事件 = 在较短时间内围绕同一主题、同一实体、同一政策、同一技术突破、同一地缘/宏观冲击形成的一组新闻簇。

这一定义适合本项目，因为它避免把单条新闻误当作因果冲击，也允许一个事件由多条新闻、多个关键词、多个主体和多个市场映射共同构成。

## 本案例最小数据口径

当前 full-fields raw 还未倒序抓到 2025-08，因此第一版先使用旧标准财联社表：

```text
data/processed/cls_telegraph/cls_telegraph_2014_20260521.parquet
```

新闻检索关键词：

```text
半导体、芯片、集成电路、晶圆、封测、光刻、存储、国产替代、
中芯国际、寒武纪、北方华创、海光信息、华虹、兆易创新、韦尔股份、中微公司
```

股票篮子第一版：

```text
stock_basic.industry 包含 半导体 / 芯片 / 集成电路
```

如果本地行业字段不足，再用申万/中信/同花顺/东财板块成分补充。

## 第一版要看的形状

1. 半导体关键词新闻日频数量是否在 2025-08-08 前后抬升。
2. 半导体股票篮子从 2025-08-08 到 2025-10-10 的累计收益。
3. 高收益个股是否集中在半导体相关股票池。
4. 价格启动和新闻密度变化的先后关系。
5. 本地是否已有半导体 ETF 或板块行情；若缺失，再从 Tushare 补。

## 失败条件

- 关键词新闻在窗口内几乎没有命中，说明旧标准表不足以支撑该案例，需要等 full-fields raw 抓回 2025 或调整关键词。
- 半导体篮子没有明显超额收益，说明 2025-08-08 这个日期需要重新界定，或者行情更多来自更窄的子主题。
- 个股表现高度分散，说明“半导体”过宽，应进一步拆成设备、材料、设计、存储、封测等子篮子。
