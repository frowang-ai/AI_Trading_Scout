下面这套研究计划，我会把它设计成**“事件归因 + 主题周期识别 + 弱预测信号”**三层结构。核心不是直接证明“所有涨跌都由事件导致”，而是更严谨地回答：

> **A股的大幅上涨/下跌是否显著集中在事件密集期？哪些事件类型最能解释大波动？事件能否在大型主题行情早期提供可识别信号？**

---

# 研究题目

**A股市场事件驱动波动的识别、归因与主题周期研究：基于财联社电报、日频个股数据、财务数据与年报文本的实证分析**

---

# 一、核心直觉与研究目标

你的直觉非常有价值，但要把它变成可验证研究，需要避免一个陷阱：
**看到上涨之后，再去找新闻解释上涨。**

所以这个研究必须区分三件事：

1. **事后归因**：大涨/大跌当天或附近，是否确实存在相关事件？
2. **事件冲击**：特定事件发生后，相关股票是否产生显著异常收益、异常波动、异常成交？
3. **周期启发**：某些事件簇是否能在主题行情早期给出信号，而不是等市场已经涨完才出现？

因此建议把研究拆成三个问题：

| 层级  | 研究问题                              | 对应结论         |
| --- | --------------------------------- | ------------ |
| 第一层 | A股主要大波动是否与事件窗口高度重合？               | 检验“事件相关性”    |
| 第二层 | 哪些 subject / 事件类型 / 新闻来源最能解释异常收益？ | 建立“事件影响图谱”   |
| 第三层 | 哪些事件特征会演化成几周到几个月的主题周期？            | 构造“主题周期早期信号” |

方法上，可以借鉴标准事件研究框架，即围绕事件窗口计算异常收益；MacKinlay 的事件研究综述是这类方法的经典参考。([JSTOR][1]) 另外，新闻主题与股票收益之间的关系可以用 topic exposure / topic signal 建模，但已有研究也提醒，监督式主题模型很容易对收益过拟合，所以你这个项目必须特别重视样本外检验和 placebo 检验。([SSRN][2])

# 二、最重要的概念定义

## 1. 什么叫“事件”？

不要把一条财联社电报直接等同于一个事件。更合理的定义是：

> **事件 = 在较短时间内围绕同一主题、同一实体、同一政策、同一技术突破、同一地缘/宏观冲击形成的一组新闻簇。**

例如，单条新闻可能只是：

* “某公司发布 AI 模型”
* “海外科技股大涨”
* “某产业链公司公告订单”
* “政策部门提到算力基础设施”
* “券商解读 AI 应用落地”

它们如果在几天内密集出现，才可能构成一个真正的市场事件簇。

所以财联社数据要至少形成三层结构：

```text
article 文章层
    ↓
subject / entity / source / sentiment 新闻特征层
    ↓
event_cluster 事件簇层
```

也就是说，`subjects` 是很重要的入口，但不能完全依赖 subject。原因是：

1. 有些 subject 很宽，比如“环球市场情报”“期货市场情报”；
2. 有些 subject 很具体，比如“中东冲突”“DeepSeek”“光模块”；
3. 一篇文章可以挂多个 subject；
4. subject 可能是事后运营归类，不一定完全稳定；
5. 同一个事件可能横跨多个 subject。

所以你要同时用：

* `subject_id / subject_name`
* 标题、正文、摘要文本
* 发布时间 `ctime`
* 来源/作者 `author`
* `level`
* 阅读、评论、分享等关注度字段
* 文章中提到的公司、行业、商品、国家、政策机构、技术名词
* 文本 embedding 或关键词聚类

来共同构造事件。

---

## 2. 什么叫“主要涨跌波动”？

这里也不能只看日收益率。建议定义多种“大波动”口径：

### 个股层面

| 类型      | 定义示例                                     |
| ------- | ---------------------------------------- |
| 单日大波动   | 个股日收益进入全市场绝对值 top 1% / top 5%            |
| 异常收益    | 扣除市场、行业、风格因子后的 abnormal return           |
| 连续上涨/下跌 | 5日、10日、20日累计异常收益进入 top 分位                |
| 涨跌停事件   | 是否涨停、跌停、连续涨停、打开涨停                        |
| 异常成交    | 换手率、成交额、量比进入历史高分位                        |
| 波动率冲击   | 日内不可得时，用日频 realized volatility proxy 或振幅 |

### 行业/主题层面

| 类型      | 定义示例                  |
| ------- | --------------------- |
| 行业大涨/大跌 | 申万/中信行业指数异常收益         |
| 主题扩散    | 相关股票上涨家数占比、涨停家数、成交额占比 |
| 板块周期    | 5日、10日、20日主题组合异常收益    |
| 市场宽度    | 同主题股票中上涨比例、跑赢市场比例     |

### 市场整体层面

| 类型         | 定义示例                         |
| ---------- | ---------------------------- |
| 指数大波动      | 沪深300、中证500、中证1000、创业板指等异常收益 |
| 风险偏好切换     | 小盘/大盘、成长/价值、科技/周期风格切换        |
| 波动率 regime | 市场波动率从低波动进入高波动区间             |

这样可以避免把“市场整体涨”误判为“某个事件导致个股涨”。

# 三、总体研究框架：三条证据链

我建议不要只做一个模型，而是做三条互相验证的证据链。

---

## 证据链 A：大波动是否集中在事件窗口？

这是最直接检验你直觉的部分。

### 核心问题

> 大涨/大跌日附近，财联社事件强度是否显著高于普通交易日？

### 构造变量

对每个交易日、每个主题/行业/股票，构造：

```text
news_count_{topic,t}
subject_count_{topic,t}
source_weighted_news_{topic,t}
novelty_{topic,t}
sentiment_{topic,t}
event_intensity_{topic,t}
```

其中最重要的是 **事件强度 event_intensity**：

```text
event_intensity_{k,t}
= 新闻数量z-score
+ 新颖度z-score
+ 来源权重
+ 相关股票覆盖度
+ 多subject共振
+ 关注度变化
```

举例：

* 1 条普通转载新闻，强度低；
* 多家来源连续报道，强度高；
* 出现新技术名词、新政策、新产业链实体，强度高；
* 文章同时挂到多个具体 subject，强度高；
* 只挂在“环球市场情报”这种宽 subject，强度低；
* 央视、交易所公告、部委政策、上市公司公告这类硬来源，强度高；
* 短视频、传闻、社媒类来源，单独权重低，但可作为情绪扩散指标。

### 检验方式

第一步做条件概率：

```text
P(事件窗口 | 大波动日)
vs
P(事件窗口 | 普通日)
```

如果大波动日附近的事件窗口概率显著高于普通日，说明“主要波动与事件相关”这个判断有初步证据。

第二步做 lift：

```text
lift = P(大波动 | 事件窗口) / P(大波动)
```

如果某些 subject 的 lift 很高，说明这些事件类型对大波动更有解释力。

第三步做回归：

```text
LargeMove_{i,t}
= α
+ β EventSignal_{i,t-1:t}
+ γ Controls_{i,t}
+ stock FE
+ date FE
+ ε
```

其中 `LargeMove` 可以是：

* 是否大涨；
* 是否大跌；
* 是否涨停；
* 是否进入 top 1% 异常收益；
* 是否出现异常成交。

控制变量包括：

* 前期收益；
* 前期波动率；
* 换手率；
* 市值；
* 行业；
* 估值；
* 盈利能力；
* 杠杆；
* 市场整体收益；
* 行业收益。

### 关键判断标准

如果结论是：

> 加入事件变量后，大波动识别能力明显提高；并且事件信号在大波动之前或至少同日早期出现，而不是完全滞后出现。

那么你的第一层假设就有支持。

---

## 证据链 B：事件研究——特定事件发生后，相关股票是否有异常收益？

这一步是最像标准金融实证的部分。

### 基本思路

对每一个事件簇 `e`，定义：

```text
event_date_e = 第一条高可信新闻出现的交易日
treated stocks = 与事件高度相关的股票
control stocks = 同行业/相似市值/相似流动性但低相关股票
```

然后计算事件窗口内的异常收益：

```text
CAR_{i,e}[-1,+1]
CAR_{i,e}[0,+3]
CAR_{i,e}[0,+5]
CAR_{i,e}[0,+20]
```

其中：

```text
AR_{i,t} = R_{i,t} - E[R_{i,t}]
```

`E[R]` 可以用几种方式估计：

1. 市场模型；
2. 行业中性模型；
3. 中国市场风格因子模型；
4. 你自己用全市场日频数据构造的 size、value、momentum、reversal、liquidity 因子；
5. 直接使用同业 matched control。

### 事件窗口建议

A股有涨跌停和情绪扩散特征，所以窗口不能只看一天。

| 窗口           | 含义              |
| ------------ | --------------- |
| `[-1, +1]`   | 检查是否有提前反应、泄露或预期 |
| `[0, +1]`    | 短期冲击            |
| `[0, +3]`    | A股常见的事件反应延迟     |
| `[0, +5]`    | 一周主题扩散          |
| `[0, +20]`   | 一个中短周期是否形成      |
| `[+21, +60]` | 是否反转或继续扩散       |

### 横截面检验

重点不是只看事件后市场有没有涨，而是看：

> 事件相关度越高的股票，是否涨得越多？

模型可以写成：

```text
CAR_{i,e}
= α
+ β Exposure_{i,e}
+ γ Controls_{i,e}
+ industry FE
+ event FE
+ ε
```

其中 `Exposure_{i,e}` 是股票对事件的暴露度。

暴露度可以来自四类信息：

| 暴露来源    | 例子                          |
| ------- | --------------------------- |
| 直接提及    | 新闻中出现公司名、股票简称、产品名           |
| 行业/概念映射 | 半导体、光模块、AI 应用、算力、机器人        |
| 年报文本相似度 | 主营业务、产品描述、客户/供应链、研发方向       |
| 财务暴露    | 海外收入占比、毛利率、资本开支、存货、周期品成本敏感度 |

年报文本在这里非常有价值。因为很多事件不会直接提到某只股票，但年报会告诉你这家公司是否真的有相关业务。

例如，AI 事件不应该让所有“软件股”都算 treated。更好的做法是：

```text
AI事件文本 embedding
vs
公司年报主营业务/研发方向 embedding
```

得到每家公司对 AI 事件的语义暴露度。

BERTopic 这类方法可以用 transformer embedding、聚类和 class-based TF-IDF 生成可解释主题，适合作为新闻主题聚类的一种工具。([arXiv][3]) 如果你希望主题随时间演化，而不是固定主题，也可以参考 dynamic topic model 的思路，它本来就是为分析文本集合中的主题时间演化设计的。([ACM Digital Library][4])

## 证据链 C：主题周期识别——事件如何演化成几周到几个月的行情？

这是你真正关心的部分。

你的目标不是预测明天涨跌，而是识别：

> 哪些事件会从“一条新闻”变成“一个主题周期”。

这要把“事件”与“行情周期”绑定起来。

# 四、如何定义 A股里的“主题周期”？

我建议把主题周期定义为：

> 某一组事件相关股票，在一段连续交易日内，出现显著超额收益、成交扩张、上涨广度扩散，并且该现象不能完全由市场或行业整体解释。

可以用四个条件识别：

| 条件   | 指标                          |
| ---- | --------------------------- |
| 收益强度 | 主题组合 5日/10日/20日累计异常收益显著为正或负 |
| 扩散广度 | 相关股票中跑赢市场比例、上涨比例、涨停家数       |
| 交易确认 | 成交额、换手率、融资买入、波动率上升          |
| 持续性  | 不是单日脉冲，而是持续若干交易日            |

形式上：

```text
ThemeCycleStart_{k,t} = 1
```

当主题 `k` 在 `t` 附近满足：

```text
CAR_{k,t:t+10} > threshold
Breadth_{k,t:t+10} > threshold
TurnoverZ_{k,t:t+10} > threshold
```

并且这个主题不是单纯跟随大盘。

---

# 五、事件到周期的机制假设

你可以把 A股主题行情理解成一个四阶段过程：

```text
事件出现
    ↓
叙事形成
    ↓
相关股票扩散
    ↓
交易拥挤 / 基本面验证 / 反转
```

对应到数据上：

| 阶段   | 新闻特征                  | 市场特征          |
| ---- | --------------------- | ------------- |
| 事件出现 | 第一条高新颖度、高可信来源新闻       | 少数直接相关股票异动    |
| 叙事形成 | 多 subject、多来源、关键词密集出现 | 概念股扩散，成交放大    |
| 周期扩散 | 新闻频率持续高位，更多公司被关联      | 涨停扩散，板块轮动     |
| 周期尾部 | 新闻密度极高但新颖度下降          | 高换手、冲高回落、分歧加大 |

所以，真正有用的不是单纯新闻数量，而是：

```text
强度 × 新颖度 × 来源可信度 × 相关股票广度 × 价格确认
```

可以构造一个主题周期早期信号：

```text
CycleSignal_{k,t}
= w1 * IntensityZ_{k,t}
+ w2 * NoveltyZ_{k,t}
+ w3 * SourceQuality_{k,t}
+ w4 * Breadth_{k,t}
+ w5 * ExposureConcentration_{k,t}
+ w6 * EarlyPriceConfirmation_{k,t}
- w7 * Crowding_{k,t}
```

解释一下：

| 变量                       | 含义                    |
| ------------------------ | --------------------- |
| `IntensityZ`             | 新闻密度相对历史是否异常          |
| `NoveltyZ`               | 事件是否新，而不是旧主题重复炒作      |
| `SourceQuality`          | 是否来自官方、公告、权威媒体、产业链硬信息 |
| `Breadth`                | 是否从少数股票扩散到多只相关股票      |
| `ExposureConcentration`  | 是否有明确受益股票，而不是泛泛叙事     |
| `EarlyPriceConfirmation` | 初期是否已有小范围价格响应         |
| `Crowding`               | 若已过度拥挤，反而可能接近尾部       |

注意最后一点很重要：
**事件信号不是越热越好。**
当新闻密度极高、全市场都在讨论、相关股票已经连续涨停时，它可能已经从“早期信号”变成“后期拥挤信号”。

# 六、财联社 subject 应该怎么用？

你现在的 subject 字段非常有价值，但我建议不要直接把 subject 当最终分类，而是先建立一个 subject 质量分层。

## 1. subject 粒度分层

| subject 类型 | 例子                   | 用法                |
| ---------- | -------------------- | ----------------- |
| 宽泛市场类      | 环球市场情报、期货市场情报、国际市场   | 作为背景变量，不直接当事件     |
| 具体主题类      | 中东冲突、AI、光模块、半导体、低空经济 | 可作为事件主题           |
| 行业板块类      | 医药、地产、券商、新能源         | 用于行业映射            |
| 公司/公告类     | 个股公告、财报、重大合同         | 用于公司事件            |
| 来源/频道类     | 央视新闻、外媒、短视频等         | 用于 source quality |

## 2. subject 诊断指标

对每个 subject 计算：

```text
subject_entropy
subject_specificity
market_relevance
return_association
event_persistence
```

### subject_entropy

如果一个 subject 下面什么新闻都有，它的信息熵很高，说明太宽泛。

### subject_specificity

如果 subject 词汇集中、实体集中、影响股票集中，说明它更像真实主题。

### market_relevance

看该 subject 出现时，相关股票是否有显著异常收益或异常成交。

### event_persistence

看 subject 是否能持续几天到几周，而不是单日新闻流。

最终可以把 subject 分成：

```text
A类：可直接用于主题事件
B类：需要结合文本聚类后使用
C类：只作为背景市场新闻
D类：噪声或低相关
```

# 七、建议建立的事件分类体系

你最终需要一套自己的事件 taxonomy，而不是完全依赖财联社原始 subject。

我建议一级分类如下：

| 一级事件类型  | 典型内容                  | 可能影响            |
| ------- | --------------------- | --------------- |
| 产业技术突破  | AI模型、半导体、机器人、低空经济、光模块 | 成长股、科技主题        |
| 产业政策    | 补贴、监管、产业规划、国产替代       | 行业整体重估          |
| 宏观流动性   | 降准、降息、财政刺激、汇率、社融      | 全市场风险偏好         |
| 地缘冲突    | 中东、俄乌、制裁、出口管制         | 军工、油气、黄金、航运、半导体 |
| 海外映射    | 美股科技、海外财报、英伟达、台积电等    | A股映射标的          |
| 商品周期    | 原油、铜、煤炭、锂、黄金、农产品      | 周期股、成本端         |
| 公司硬事件   | 订单、并购、重组、定增、业绩预告      | 个股或产业链          |
| 财报/基本面  | 年报、季报、盈利拐点、库存周期       | 持续性行情           |
| 市场制度/监管 | IPO、减持、融券、量化、交易规则     | 风格切换、流动性        |
| 舆情/情绪扩散 | 短视频、社媒热词、传闻、概念发酵      | 短期交易性行情         |

这套分类应该允许一条事件有多个标签，例如：

```text
DeepSeek / AI事件
= 产业技术突破
+ 海外映射
+ 国产替代
+ 算力需求
+ 软件应用
```

# 八、股票与事件如何匹配？

这是整个研究成败的核心。

不要只用“新闻里有没有提到股票名”。A股主题行情经常是：

> 新闻没有提到公司，但市场认为公司受益。

所以要构建多层 exposure。

## 1. 直接实体匹配

从新闻里识别：

* 股票简称；
* 公司全称；
* 产品名；
* 董事长/实控人；
* 关联品牌；
* 产业链企业；
* 地名和园区。

这一步精度高，但召回低。

## 2. 行业/概念映射

用申万行业、中信行业、概念板块、财联社 subject、plate_id 等做映射。

例如：

```text
光模块事件 → 光通信、CPO、数据中心、通信设备
AI模型事件 → 算力、服务器、软件、传媒、应用、芯片
中东冲突 → 油气、黄金、航运、军工
```

这一步召回高，但可能有噪声。

## 3. 年报文本语义匹配

这是你数据里非常有价值的一块。

做法：

```text
事件文本 embedding
公司年报主营业务 embedding
公司年报研发方向 embedding
公司年报风险因素 embedding
公司产品描述 embedding
```

然后计算相似度，得到：

```text
Exposure_{i,e}^{text}
```

这样可以识别出那些没有被新闻直接点名、但业务真实相关的股票。

## 4. 财务暴露匹配

用财务数据判断事件影响是否有基本面支撑。

例如：

| 事件   | 财务暴露                   |
| ---- | ---------------------- |
| 商品涨价 | 存货、毛利率、原材料成本、上游/下游属性   |
| AI算力 | 资本开支、研发费用、服务器/芯片/光模块业务 |
| 出口管制 | 海外收入占比、客户集中度           |
| 利率变化 | 资产负债率、财务费用、金融资产        |
| 地产政策 | 房地产收入占比、应收账款、存货        |

最终暴露度可以写成：

```text
Exposure_{i,e}
= a * DirectMention
+ b * IndustryMatch
+ c * AnnualReportSimilarity
+ d * FinancialExposure
+ e * HistoricalSensitivity
```

# 九、核心实证模型

## 模型 1：事件解释大波动

```text
LargeMove_{i,t}
= α_i
+ δ_t
+ β1 EventIntensity_{i,t-1}
+ β2 EventIntensity_{i,t}
+ β3 EventNovelty_{i,t-1:t}
+ β4 SourceQuality_{i,t-1:t}
+ γ Controls_{i,t-1}
+ ε_{i,t}
```

其中：

* `α_i` 是股票固定效应；
* `δ_t` 是日期固定效应；
* `Controls` 包括市值、估值、前期收益、波动率、换手率、行业收益等。

如果 `β1` 或 `β2` 显著，说明事件信号与大波动相关。

更严格地说，`β1` 比 `β2` 更重要，因为 `t-1` 的事件更接近提前信号；`t` 的事件可能已经是市场反应后的报道。

---

## 模型 2：事件研究 CAR

```text
CAR_{i,e}[0,h]
= α_e
+ β Exposure_{i,e}
+ γ Controls_{i,e}
+ industry FE
+ ε_{i,e}
```

其中 `h` 可以取：

```text
1, 3, 5, 10, 20
```

如果 `β > 0`，说明事件相关度越高的股票，在事件后涨得越多。

如果是利空事件，则预期 `β < 0`。

---

## 模型 3：主题周期启动概率

```text
CycleStart_{k,t}
= α
+ β1 IntensityZ_{k,t-1:t}
+ β2 NoveltyZ_{k,t-1:t}
+ β3 SourceQuality_{k,t-1:t}
+ β4 Breadth_{k,t-1:t}
+ β5 EarlyPriceConfirmation_{k,t-1:t}
+ β6 MarketRiskAppetite_t
+ ε_{k,t}
```

这个模型回答：

> 哪些事件更容易从新闻变成主题行情？

这里的 `k` 是主题，比如 AI、半导体、光模块、油气、军工、地产、券商等。

---

## 模型 4：收益解释的增量贡献

建立两个模型：

```text
Baseline Model:
Return / LargeMove ~ 市场变量 + 行业变量 + 风格变量 + 财务变量
```

然后加入事件变量：

```text
Event Model:
Return / LargeMove ~ 市场变量 + 行业变量 + 风格变量 + 财务变量 + 事件变量
```

比较：

```text
ΔR²
ΔAUC
Δlog-loss
precision@k
top big-move recall
```

如果加入事件变量后，对大波动识别能力明显提升，就能支持你的核心判断。

注意，这里重点不是普通日收益的 R²，而是：

> **尾部波动、大涨大跌、主题周期启动的解释能力。**

A股普通交易日可能很难被新闻解释，但大波动日可能高度事件驱动。

# 十、时间顺序必须特别严格

这是整个研究最容易出错的地方。

财联社文章有精确 `ctime`，但股票数据是日频，所以必须把新闻映射到交易日时间桶：

| 新闻发布时间         | 归属           |
| -------------- | ------------ |
| 前一交易日收盘后到当日开盘前 | 可用于解释当日收益    |
| 当日 9:30 前      | 可用于解释当日收益    |
| 当日交易时段         | 对日频数据来说存在模糊性 |
| 当日 15:00 后     | 只能解释下一交易日收益  |
| 周末/节假日         | 映射到下一交易日     |

最严谨的做法是拆成三种事件变量：

```text
PreMarketNews_{t}
IntradayNews_{t}
PostMarketNews_{t}
```

其中真正能用于“提前信号”的是：

```text
PostMarketNews_{t-1} + PreMarketNews_{t}
```

对于交易时段内发布的新闻，因为你没有分钟级行情，不能确定是新闻导致价格，还是价格异动导致新闻报道。所以这类新闻可以用于“事件相关性”，但不适合直接宣称为“预测信号”。

# 十一、反向因果和事后叙事问题

你的研究一定要防止这种情况：

> 股票先涨了，财联社再发新闻，最后我们误以为新闻导致上涨。

所以要做几个审计。

## 1. 第一条新闻时间审计

对每个事件簇记录：

```text
first_news_time
first_price_move_date
```

然后分成：

| 类型            | 解释强度    |
| ------------- | ------- |
| 新闻明显早于价格      | 强事件驱动证据 |
| 新闻与价格同日       | 中等证据    |
| 价格先动、新闻后发     | 更像事后解释  |
| 新闻长期存在但价格最近才动 | 需要结合催化剂 |

## 2. pre-event return 检查

在事件前计算：

```text
CAR[-20,-1]
CAR[-10,-1]
CAR[-5,-1]
```

如果事件前已经大涨，事件后继续涨，可能说明：

* 市场已有预期；
* 有信息泄露；
* 财联社报道滞后；
* 或者事件只是强化叙事。

这类事件不能简单当作“新闻触发”。

## 3. placebo 日期

对每个事件随机平移日期，例如：

```text
event_date - 30
event_date + 30
随机同主题非事件日
```

如果真实事件窗口的 CAR 明显强于 placebo，证据才更可信。

## 4. placebo 股票

对每个事件选择：

* 同行业但低 exposure 股票；
* 同市值、同换手但低 exposure 股票；
* 随机股票组合。

如果高 exposure 股票显著强于 placebo 股票，说明事件匹配有效。

# 十二、如何判断“主要与什么事件相关”？

最终可以输出一张事件影响力排行榜。

每个 subject / 事件类型计算：

```text
impact_score
= 大波动覆盖率
+ 异常收益强度
+ 异常成交强度
+ 主题持续性
+ 样本外稳定性
- 反向因果惩罚
- 过拟合惩罚
```

建议指标如下：

| 指标                | 含义               |
| ----------------- | ---------------- |
| BigMove Coverage  | 该事件类型覆盖了多少大涨/大跌日 |
| Average CAR       | 事件后相关股票平均异常收益    |
| Median CAR        | 防止被少数极端值支配       |
| Hit Rate          | 正向事件后相关股票上涨比例    |
| Turnover Shock    | 成交放大程度           |
| Breadth Expansion | 涨幅是否从少数股票扩散到板块   |
| Half-life         | 事件影响持续几天         |
| Reversal Rate     | 后续是否快速反转         |
| Lead Ratio        | 新闻先于价格的比例        |
| OOS Stability     | 样本外是否仍然有效        |

这样你可以得到类似：

| 事件类型   | 影响方向    | 典型持续期 | 大波动解释力 | 适合用途     |
| ------ | ------- | ----- | ------ | -------- |
| 产业技术突破 | 多为上涨    | 数日到数周 | 高      | 主题周期识别   |
| 产业政策   | 方向取决于政策 | 数日到数月 | 高      | 行业配置     |
| 海外映射   | 多为短期    | 1-5日  | 中高     | 隔夜/映射交易  |
| 地缘冲突   | 方向分化    | 数日到数周 | 中      | 商品、军工、避险 |
| 公司公告   | 个股为主    | 1-5日  | 高      | 个股事件研究   |
| 财报业绩   | 个股/行业   | 数日到季度 | 中高     | 基本面验证    |
| 社媒舆情   | 短期      | 1-3日  | 不稳定    | 情绪监控     |

# 十三、一个很重要的结论假设

我预计最后结果可能不是：

> A股所有上涨下跌都由事件驱动。

更可能是：

> A股的普通日收益很难被事件解释，但尾部波动、主题行情、涨跌停扩散和风格切换高度依赖事件。
> 事件对“波动率”和“大行情启动”的解释力，可能显著高于对“日常收益”的解释力。

所以研究重点应该放在：

```text
大波动
异常收益
主题扩散
涨跌停
成交放大
周期启动
```

而不是试图解释每一天每只股票的普通涨跌。

# 十五、必须做的稳健性检验

这个研究很容易被质疑，所以稳健性非常重要。

## 1. 多重检验控制

subject 很多，事件很多，股票很多，容易数据挖掘。

需要做：

```text
FDR correction
Bonferroni / Benjamini-Hochberg
out-of-sample split
rolling window validation
```

## 2. 宽 subject 剔除

把“环球市场情报”“国际市场”“期货市场情报”等宽泛 subject 剔除后，结果是否还成立？

如果剔除宽 subject 后结果更强，说明真正起作用的是具体事件，而不是新闻总量。

## 3. 来源可信度分组

按来源分组：

```text
官方/公告
主流媒体
财联社原创
外媒
研报/市场传闻
短视频/社媒
```

看哪类来源更有冲击力。

## 4. 牛熊市分组

事件驱动在不同市场环境下可能完全不同。

分组：

```text
强市场
弱市场
震荡市
高流动性
低流动性
高风险偏好
低风险偏好
```

同一个事件在牛市可能是上涨催化剂，在熊市可能没有反应。

## 5. 大盘日固定效应

很多事件和市场整体情绪同时发生。

必须加入：

```text
date fixed effects
industry × date controls
market return controls
```

否则容易把大盘上涨误判成事件效果。

## 6. 交易时间分组

分开检验：

```text
收盘后新闻
开盘前新闻
盘中新闻
收盘后新闻对下一日影响
```

只有前两类更适合谈提前信号。

# 十八、最关键的研究判断标准

最后我会用下面这套标准判断研究是否成功。

## 支持你假设的证据

如果出现以下结果，就强烈支持你的判断：

1. 大涨/大跌日的事件强度显著高于普通日；
2. 具体 subject 的事件窗口能覆盖大量尾部波动；
3. 高 exposure 股票在事件后显著跑赢低 exposure 股票；
4. 新闻先于价格的事件，比新闻滞后价格的事件有更强解释力；
5. 加入事件变量后，大波动识别能力明显提升；
6. 某些事件类型具有稳定的周期启动能力；
7. 事件变量对尾部收益、涨停、成交扩张的解释力高于对普通日收益的解释力。

## 不支持你假设的证据

如果出现以下结果，就说明原假设需要修正：

1. 大波动日新闻并不比普通日多；
2. 大部分新闻都在价格之后出现；
3. subject 只是宽泛标签，无法区分真实事件；
4. 高 exposure 股票并不比低 exposure 股票反应强；
5. 事件变量只在样本内有效，样本外失效；
6. 加入事件变量后模型提升很小；
7. 事件解释主要来自少数历史案例，而不是全样本规律。

# 十九、我对这个研究的总体判断

我认为这个研究非常值得做，而且很适合 A股。
但它最后最有可能得到的不是一句简单结论，而是一套分层结论：

> **A股不是所有波动都由事件驱动，但大幅波动、主题行情、涨跌停扩散、成交放大和风格切换，很可能显著依赖事件。**
> **其中最有价值的不是单条新闻，而是“高新颖度、高可信来源、多主体共振、相关股票扩散、价格初步确认”的事件簇。**
> **财联社 subject 是非常好的入口，但真正的研究对象应该是 subject + 文本 + 来源 + 实体 + 股票暴露共同构造出来的事件图谱。**

如果你要把它做成严谨研究，我建议最终标题可以更聚焦一些：
